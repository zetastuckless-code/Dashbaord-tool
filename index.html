              Set up your daily automations

              Two automations keep the dashboard current without any copying and pasting. The morning brief turns your Outlook, Jira, and Slack into a to-do list for each client. Report uploads bring new client reports in on their own. Work through the steps in order; each one shows a check when it is done.

              Morning brief and to-dos

              1. Add your clients to the dashboard

                The brief is written per client, and the prompt you copy in step 4 lists every client on the dashboard. So add your clients first. The quickest way is to upload each client's insertion order (IO). That creates the client and its campaign.

              2. Make a folder for the brief in OneDrive

                ChatGPT saves each morning's brief as a file, and the dashboard picks it up from there. On your Mac, open Finder, click OneDrive in the sidebar, and create a new folder named:

                Northstar To-dos

                On Windows, use File Explorer › OneDrive. You can use another name; change it in step 4 so the prompt matches.

              3. Connect that folder to the dashboard

                Use Chrome or Edge (Safari can't watch a folder). Click the button, pick the folder from step 2, and choose Allow. If Chrome offers Allow on every visit, pick that so it never asks again.

              4. Fill in your details and copy the prompt

                These details go straight into the prompt. Anything left blank shows as [brackets] so you can see what is missing. They're saved in this browser.

              DCM and DSP email reports
              
          
              DCM (CM360) and the DSP send their scheduled reports to Outlook with the file attached. A Power Automate flow saves each one into a OneDrive folder, and the dashboard picks it up from there. For 1P clients the DSP report is the spend itself, so it’s used first; DCM fills in for everyone else. DCM fills in each line’s spend, delivery, and pacing for the days after its latest full report, so you stay current between weekly reports. When the next report arrives, it takes over those days. Flashtalking sends a download link, not a file, so it isn’t covered here.
              
          
                
            
              1. 
              
                Make a DCM folder in your own OneDrive
                
              
                  
                
                1. In Finder › OneDrive (or onedrive.com), make a folder named DCM Reports in your own files.
                  2. 
                
                2. Keep it out of the shared SharePoint folder. Your DCM files then stay yours and don’t show up on teammates’ dashboards.
                  3. 
              
                
            
                2. 
            
              2. 
              
                Build the flow in Power Automate
                
              
                  
                
                1. Go to make.powerautomate.com and sign in with your work account.
                  2. 
                
                2. Click Create › Automated cloud flow. Name it DCM reports to dashboard, pick the trigger When a new email arrives (V3) (Office 365 Outlook), and click Create.
                  3. 
                
                3. In the trigger, set Folder to where the report emails land. It starts on Inbox. If an Outlook rule moves them into a folder like Auto Reporting, click the folder icon and pick that folder instead. The flow only watches that one folder, not the folders inside it.
                  4. 
                
                4. In the trigger, open Advanced options and set Include Attachments to Yes, Only with Attachments to Yes, and Subject Filter to Report #. Every scheduled CM360 email starts that way, for example Report #1750693127 : "Nature's Sunshine 2026_Zeta". To take only one client’s report, put its name in the filter instead, like Nature's Sunshine 2026_Zeta.
                  5. 
                
                5. Click + New step, search for Create file, and pick the OneDrive for Business one.
                  6. 
                
                6. Set Folder Path to /DCM Reports. Set File Name to the Attachments Name value and File Content to Attachments Content (from the dynamic content list). Power Automate wraps the step in Apply to each on its own; that’s expected.
                  7. 
                
                7. Click Save. When the next DCM email arrives, its file appears in DCM Reports within a few minutes. To test now, forward yesterday’s DCM email to yourself with the same subject. If your rule sorts by sender, the forward stays in your Inbox, so drag it into the report folder for the test.
                  8. 
                
                8. For DSP reports, open the flow, click Save As, and name the copy DSP reports to dashboard. Change its Subject Filter to text from your DSP report emails’ subject, and keep the same /DCM Reports folder. One folder holds both. If your DSP emails land in a different Outlook folder, change the copy’s Folder too.
                  9. 
              
                
              
                In File Name and File Content, don’t type anything: click into the box, open the dynamic content list (the lightning bolt, or type /), and pick Attachments Name and Attachments Content. Each email’s own file name is used, so every day’s file is kept. If the DSP names every file the same (like export_1.csv), set File Name with the expression concat(formatDateTime(utcNow(),'yyyy-MM-dd_HHmm'),'_',items('Apply_to_each')?['name']) so files don’t overwrite each other.
                
            
                3. 
            
              3. 
              
                Connect the folder
                
              
                In Chrome or Edge, pick the DCM Reports folder. The dashboard checks it along with your report folder. A campaign named like one on the dashboard imports on its own; DSP and DCM line items or placements go to the line whose name they carry. If the name differs, its first file waits on Report review so you can pick the campaign once; after that, each day’s file imports on its own.
